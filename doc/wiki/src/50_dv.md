# Verification

## TL;DR

512 standalone DV cases across 4 buckets (`B`/`E`/`P`/`X`) and 32
integration cases under `tb_int` cover the central-trigger refresh.
Coverage profiles are pre-computed per case for both isolated runs and
random-promoted long-run soak in `bucket_frame` / `all_buckets_frame`
modes.

## Why this exists

The IP is the trusted hit source for every Mu3e online datapath
testbench. Any mis-decoded TCC, dropped cluster, or malformed type0
packet here propagates everywhere downstream. Closure requires per-case
isolated UCDBs, merged isolated coverage tables, and continuous-frame
soak runs — not just "the tests pass".

### Coverage profiles

`tb/cov_profiles.json` carries the per-case coverage bin ownership and
random-promotion knob ranges for all 512 standalone cases. The loader
at `tb/uvm/cov_profile_loader.svh` is Questa-FSE compatible (no
`covergroup`, no `rand`, no DPI) and provides:

- `cov_record_bins(string case_id)` — increments the per-bin counters
  this case is responsible for hitting
- `cov_promoted_value(string case_id, string knob_name)` — returns the
  LCG-randomised value for the named knob, centred on the case's
  directed value (used in `bucket_frame` / `all_buckets_frame` soak)
- `cov_case_is_promoted(string case_id)` — true if this case has any
  knob to promote in soak mode

**Counts:** 273 coverage bins exercised, 1250 total bin-touches, mean
2.44 bins per case. 408 directed cases stay directed, 104 cases get
random-promoted in soak.

### Run modes (per dv-workflow §8-9)

- **isolated** — one case per simulation, fresh DUT start, per-case
  UCDB. Default mode for sign-off evidence.
- **bucket_frame** — all 128 cases in one bucket run in case-id order
  in one continuous timeframe; random-promoted via `cov_profile_loader`.
- **all_buckets_frame** — all 4 buckets in one continuous timeframe;
  same random promotion.

### Formal harness

`tb/formal/emulator_mutrig_formal.sv` binds 5 SVA property modules
(assume/cover/assert) into `frontend_run_ctl`, `frontend_trigger_engine`,
`prbs15_lfsr`, `be_mutrig_lane_type0_emit`, and
`be_mutrig_lane_emitter`. Properties cover one-hot run-control,
RR overflow monotonicity, PRBS-15 never-zero, type0 SOP/EOP/endofrun
structure, and per-lane counter monotonicity. Bind container compiles
clean under `qverify -modes lint,cdc,rdc,formal`.

## Open questions / gotchas

- The UVM testbench itself is not yet implemented (case skeletons exist
  in DV_BASIC etc.; UVM wiring is the next codex2 deliverable).
- Coverage profile loader is hard-coded (no DPI) per the Questa FSE
  Starter Edition constraint documented in `/home/yifeng/CLAUDE.md`.
  Regenerate via `python3 tb/script/build_cov_profiles.py` if the case
  set or random profiles change.
- Formal SVA properties compile clean but won't be reported as
  "Proven" by `qverify` until the bind container module is invoked
  from a UVM TB top — `vlog` without `-mfcu` does not auto-elaborate
  CU-scope binds. Documented in the harness header.
